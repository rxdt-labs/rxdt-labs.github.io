Reactive programming redefined.

At rxdt labs, we work on making reactive programming simpler so that you can stop worrying about manual updates. Instead of assigning variables, we equate variables so everything remains up-to-date when their children change. This change of mindset makes code less cluttered with re-assignment, making everything easier to write and read.
